# SANNIS: Umbau /erfahrungsberichte/

Visuelle Vorschau des geplanten Umbaus der Seite
https://sannis.at/erfahrungsberichte/

**Vorschau ansehen:** siehe GitHub Pages Link in der Repo-Beschreibung

## Was man sieht

Die Seite besteht nach dem Umbau aus zwei Teilen:

1. **Der neue Inhaltsblock** (oberhalb der grauen Trennlinie). Den setzt Laura
   als ein einziges HTML-Widget in Elementor ein.
2. **Kommentare und Formular** (unterhalb der Trennlinie). Die rendert
   WordPress wie bisher. Die 53 vorhandenen Beiträge bleiben unverändert.

In der Vorschau sind die **echten 53 Kommentare** von sannis.at eingesetzt,
damit man das Auf- und Zuklappen und die Sprünge zu einzelnen Kommentaren
wirklich testen kann.

## Was funktioniert und getestet werden kann

- Die sieben Reiter unter "Erfahrungen nach Produkt"
- "Alle Erfahrungsberichte und unsere Antworten anzeigen" am Ende der Liste
- Die Links "Kommentar im Original ansehen" unter den Zitaten
- Die elf Fragen im FAQ-Bereich
- Alle Produkt- und Kategorielinks (öffnen sannis.at in einem neuen Tab)
- Die drei Buttons "Erfahrung schreiben"
